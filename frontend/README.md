# ScholarshipHunter AI — Frontend Application

Modern, bilingual (English & Hindi) single-page application built with React 18, Vite, and TailwindCSS.

**Built by Team Catalyst — Modern College of Engineering, Pune**  
*PRAGYANTRA 2026*

---

## 🌟 Features

- 🎯 **AI Match Dashboard**: Visualizes eligibility match scores (0–100%) and win probability.
- 💬 **Interactive AI Chatbot**: Always-accessible scholarship guidance companion.
- 📁 **Document Vault**: Upload certificates with Gemini Vision data extraction.
- ✍️ **AI Essay Studio**: Write and manage SOPs in English or Hindi.
- ⏰ **Deadline Tracker**: Urgency countdowns with warning badges.
- 🌍 **100% Bilingual**: Instant language toggle across all pages and content.

---

## 🛠️ Tech Stack

- **Framework**: React 18 (Hooks, Context, Memoization)
- **Bundler**: Vite 6
- **Styling**: TailwindCSS 3 + Custom Glassmorphism Theme
- **Routing**: React Router 7
- **HTTP Client**: Axios with JWT Interceptors & Auto-Logout Handling
- **Icons**: Lucide React
- **Notifications**: React Hot Toast

---

## 📦 Local Development

```bash
# Install dependencies
npm install

# Start development server with API proxy
npm run dev
```

- App URL: `http://localhost:5173`
- Production Build: `npm run build`
